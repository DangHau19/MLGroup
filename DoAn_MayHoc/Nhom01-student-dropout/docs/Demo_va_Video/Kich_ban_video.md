# Kịch bản video demo

Thời lượng dự kiến 2–4 phút. Triết phụ trách dựng từ bản demo đã kiểm tra.

| Phần | Nội dung quay | Nguồn hoặc phiên bản |
|---|---|---|
| Giới thiệu | Bài toán và chức năng demo | |
| Nhập dữ liệu | Một mẫu hợp lệ và cách hiểu các trường | |
| Dự đoán | Nhãn, xác suất ba lớp, mô hình và tập biến | |
| Giải thích | Yếu tố quan trọng và phạm vi diễn giải | |
| Kết thúc | Kết quả chính, hạn chế và nơi xem mã | |
