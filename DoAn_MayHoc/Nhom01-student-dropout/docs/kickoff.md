# Họp kickoff Nhóm 1 (30-40 phút)

**Thành phần:** 5 thành viên. **Chủ trì:** SV1 Quốc. **Ghi biên bản:** SV5 Triết.

## Agenda

1. **Mục tiêu và RQ (5')**: nhắc lại bài toán, 4 RQ, sản phẩm phải nộp (báo cáo, slide, poster, code, video demo, bảng đóng góp).
2. **Công việc từng người (10')**: đọc bảng phân công, hỏi lại phần chưa rõ; chốt ai làm poster (đề xuất SV2) và video demo (đề xuất SV5), vì proposal chưa giao rõ.
3. **Quy ước kỹ thuật (10')**: cấu trúc repo, `config.py`/`data.py`/`evaluate.py` dùng chung, 3 tập đặc trưng A/B/C, tập test chỉ dùng một lần, tiền xử lý trong Pipeline.
4. **Quy trình Git (5')**: branch theo tên, Pull Request, commit nhỏ 3-4 lần/tuần/người, Issues/Project board.
5. **Lịch họp và mốc (5')**: họp 15 phút cuối mỗi tuần; mốc Tuần 2 là EDA xong và `preprocessing.py` v1 đã merge.

## Việc cần mỗi người làm ngay sau họp (hạn: cuối Tuần 1)

- [ ] Tạo/kiểm tra tài khoản GitHub cá nhân; gửi username cho nhóm trưởng.
- [ ] Chấp nhận lời mời Collaborator vào repo chính.
- [ ] Clone repo, tạo venv, `pip install -r requirements.txt`.
- [ ] Chạy `python scripts/download_data.py` (SV2 chịu trách nhiệm xác minh dữ liệu).
- [ ] Tạo branch của mình và có ít nhất 1 commit đầu tiên.
- [ ] Chia sẻ GitHub cá nhân với giảng viên (mỗi người tự làm).
