# Thư mục minh chứng (evidence)

Đề bài yêu cầu "code liên quan + minh chứng". Mỗi thành viên bỏ minh chứng của mình vào đây. A tổng hợp trước khi nộp.

| Thứ cần có | Ai làm | Lưu ở đâu |
|---|---|---|
| Ảnh chụp **Leaderboard** Kaggle thấy rõ tên tài khoản + điểm + thời gian | A (và bất kỳ ai nộp bài) | `leaderboard/` |
| Ảnh chụp trang **My Submissions** thấy các lần nộp và điểm public | A | `leaderboard/` |
| `submission_log.csv` (ghi bằng `common.log_submission`) | Ai nộp thì ghi | `evidence/submission_log.csv` |
| File `*_cv.json` + `*_oof.npy` của từng mô hình | D, E | `cv_logs/` (tự sinh bởi `save_oof`) |
| Ảnh chụp tiến trình làm việc nhóm (Git commit log / họp nhóm / nhóm chat) | A | `team_work/` |
| Output chạy notebook (đã chạy hết cell, còn output) | Từng người | `code/` |

Quy tắc:
- Ảnh đặt tên `YYYYMMDD_mota.png`, ví dụ `20261112_leaderboard_best.png`.
- Ảnh leaderboard phải thấy **tên tài khoản Kaggle** (nếu cả nhóm dùng chung một tài khoản thì ghi rõ trong README gốc).
- Không xóa file log, chỉ thêm.
